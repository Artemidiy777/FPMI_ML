# 5. Numpy-приёмы из семинара

Всё, что в коде используется без объяснений. Проверено запуском.

## np.newaxis — добавить размерность

```python
a = np.array([1., 2., 3.])

a            ->  (3,)      одномерный массив
a[:, None]   ->  (3, 1)    столбец
a[None, :]   ->  (1, 3)    строка
```

`np.newaxis` и `None` — **одно и то же**, второе короче. В семинаре пишут `np.newaxis` для читаемости.

Зачем нужно: sklearn и матричные формулы требуют **двумерные** массивы. Одномерный `(50,)` для них не таблица.

```python
regressor.fit(X_train[:, np.newaxis], y_train)
#                     ^^^^^^^^^^^^^^ превращаем (25,) в (25, 1)
```

## Бродкастинг — главная ловушка

Numpy умеет складывать массивы разных форм, «растягивая» их. Обычно это удобно, но иногда калечит данные молча:

```
(3,1) − (3,)   ->  (3, 3)     МАТРИЦА всех попарных разностей!
(3,1) − (3,1)  ->  (3, 1)     то, что нужно
```

Именно поэтому в `fit` стоит `y = y[:, np.newaxis]`. Без него `y_pred − y` даст матрицу `ℓ×ℓ` вместо столбца, код не упадёт, а результат будет мусором.

**Как защищаться:** печатать `.shape` при отладке и ставить `assert`, как делают авторы семинара:

```python
assert grad.shape == self.w.shape, f"gradient shape {grad.shape} != weight shape {self.w.shape}"
```

## @ против *

```python
A = [[1, 2],      B = [[5, 6],
     [3, 4]]           [7, 8]]

A @ B  ->  [[19, 22],      матричное умножение (строка на столбец)
            [43, 50]]

A * B  ->  [[ 5, 12],      поэлементное (каждый с каждым на своём месте)
            [21, 32]]
```

В формулах линейной регрессии нужен **только `@`**. Если написать `*`, ошибки может не быть, а результат будет неправильным.

`@` появился в Python 3.5. Раньше писали `np.dot(A, B)` или `A.dot(B)` — встретишь в старом коде.

## .T — транспонирование

Переворачивает матрицу: строки становятся столбцами.

```
(6, 2).T  ->  (2, 6)
```

В формуле `Xᵀ(y_pred − y)` транспонирование нужно для совпадения размерностей:

```
X          (ℓ, n+1)
X.T        (n+1, ℓ)
ошибки     (ℓ, 1)

X.T @ ошибки  ->  (n+1, 1)    ← совпадает с формой весов
```

Правило: `(a, b) @ (b, c) = (a, c)`. Внутренние размеры обязаны совпасть.

## hstack — склеить по горизонтали

```python
np.hstack((X, np.ones((l, 1))))

X          (3, 1)
+ единицы  (3, 1)
=          (3, 2)
```

Приклеивает справа. Есть и `vstack` — приклеивает снизу.

`np.ones((l, 1))` создаёт столбец из `l` единиц. Двойные скобки обязательны: внутри кортеж с формой.

## Индексация массивом

```python
M.shape = (6, 2)
inds = [0, 3, 5]

M[inds]  ->  [[ 0,  1],      строки 0, 3 и 5
              [ 6,  7],
              [10, 11]]
```

Передаёшь список номеров — получаешь только эти строки, в указанном порядке. Это и используется в SGD для выборки батча.

## np.random.choice

```python
np.random.choice(np.arange(10), 5, replace=False)  ->  [2, 9, 6, 4, 0]   без повторов
np.random.choice(np.arange(10), 5, replace=True)   ->  [7, 6, 9, 2, 4]   повторы возможны
```

`replace=False` в SGD означает: один объект не попадёт в батч дважды.

## np.linalg.inv — обратная матрица

```python
np.linalg.inv(A)   # A⁻¹
```

Используется в точной формуле. Два предупреждения:

1. **Матрица может не иметь обратной** — тогда вылетит `LinAlgError: Singular matrix`. Бывает, если один признак — точная копия другого.
2. **Дорого** — порядка `n³` операций. На практике вместо `inv(A) @ b` пишут `np.linalg.solve(A, b)`: быстрее и точнее.

## np.linspace и np.random.randn

```python
np.linspace(-5, 5, 50)      50 чисел от −5 до 5 с равным шагом
np.random.randn(50)         50 случайных из нормального распределения
```

Используются для генерации искусственных данных:

```python
X = np.linspace(-5, 5, 50)
y = 5 * X + 6 + np.random.randn(50) * 5
#   ↑известная прямая  ↑шум, множитель 5 задаёт разброс
```

Приём полезный: когда правильный ответ известен заранее, легко проверить, находит ли его модель.

## Шпаргалка по формам

Пройдёмся по всему пути вычислений:

```
X              (ℓ, n)        исходные признаки
X[:, None]     (ℓ, 1)        если признак один
X_train        (ℓ, n+1)      после добавления единиц
w              (n+1, 1)      веса
y              (ℓ,)          исходные ответы
y[:, None]     (ℓ, 1)        после newaxis

y_pred = X_train @ w          (ℓ, n+1) @ (n+1, 1) = (ℓ, 1)
ошибки = y_pred − y           (ℓ, 1)
grad   = X_train.T @ ошибки   (n+1, ℓ) @ (ℓ, 1) = (n+1, 1)   = форма w ✓
```

Если где-то форма не сошлась — ищи пропущенный `newaxis` или лишний `.T`.
