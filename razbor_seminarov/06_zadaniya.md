# 6. Напиши эти классы сам

Чтение чужого кода создаёт ложное чувство понимания. Проверить себя можно только одним способом — написать с нуля.

## Как работает тренажёр

```
praktika/
├── my_regression.py        ← сюда пишешь ты
└── test_my_regression.py   ← запускаешь для проверки
```

В `my_regression.py` лежат три класса с пустыми методами:

```python
def fit(self, X, y):
    """X: (ℓ, n) признаки, y: (ℓ,) ответы.

    Шаги:
    1. привести к np.array
    2. сделать y столбцом через np.newaxis
    3. добавить к X столбец единиц
    4. посчитать веса по формуле
    5. вернуть self
    """
    raise NotImplementedError
```

Описание шагов есть, кода нет. Заменяешь `raise NotImplementedError` своей реализацией.

## Порядок

Идти строго по очереди, каждый следующий класс опирается на предыдущий.

### 1. `MyLinearRegression.fit`

Точная формула `w = (XᵀX)⁻¹Xᵀy`. Разбор — в [главе 2](02_analiticheskoe.md).

Понадобится: `np.array`, `np.newaxis`, `np.hstack`, `np.ones`, `np.linalg.inv`, `@`, `.T`

### 2. `MyLinearRegression.predict`

Добавить столбец единиц и умножить на веса. Три строки.

### 3. `MyLinearRegression.get_weights`

Одна строка. Подвох в том, что нужна **копия** — тест это проверяет.

### 4. `MyGradientLinearRegression._calc_gradient`

Формула `(2/ℓ)·Xᵀ(y_pred − y)`. Одна строка.

Тест проверяет на наших четырёх точках: в начале координат градиент должен быть ровно `(−35, −12)` — те самые числа из [ml_math](../../ml_math/04_chastnye.md).

### 5. `MyGradientLinearRegression.fit`

Цикл спуска. Разбор — в [главе 3](03_gradientnoe.md).

Не забудь про `self.losses` — отдельный тест проверяет, что история записывается и потери падают.

### 6. `MySGDLinearRegression._calc_gradient`

Тот же градиент, но по случайному батчу. Разбор — в [главе 4](04_sgd.md).

Понадобится: `np.random.choice` с `replace=False`, индексация массивом.

## Если тест не проходит

Он говорит, что именно разошлось:

```
НЕ СОШЛОСЬ  MyLinearRegression: веса совпали с sklearn
            наклон: твой 4.812345, sklearn 4.949400
```

Типичные причины:

| симптом | скорее всего |
|---|---|
| `наклон` сошёлся, `b` нет | забыл столбец единиц в `predict` |
| форма предсказаний не та | пропущен `np.newaxis` |
| градиент не та форма | лишний или недостающий `.T` |
| `get_weights` вернул ссылку | нужен `.copy()` |
| спуск не сошёлся | мало итераций или маленький `lr` |
| потери растут | `lr` велик, или перепутан знак в шаге |

Шпаргалка по формам — в [главе 5](05_numpy.md), в самом конце.
